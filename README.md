# Madhav Rathod - Portfolio Website

A modern, responsive portfolio website built with React, Vite, and Tailwind CSS. This portfolio showcases my skills as a Full Stack Developer and includes interactive elements, smooth animations, and a contact form.

## 🚀 Features

- **Responsive Design**: Optimized for all device sizes
- **Modern UI/UX**: Clean, professional design with smooth animations
- **Interactive Elements**: Custom cursor, loading animations, and hover effects
- **Contact Form**: Integrated EmailJS for seamless communication
- **Project Showcase**: Detailed project descriptions with live links
- **Skills Display**: Interactive skill icons with hover effects
- **Accessibility**: ARIA labels and semantic HTML for better accessibility

## 🛠️ Technologies Used

- **Frontend**: React 19, Vite 6
- **Styling**: Tailwind CSS 4, Material-UI
- **Animations**: AOS (Animate On Scroll)
- **Email Service**: EmailJS
- **Icons**: Font Awesome, Devicons
- **Deployment**: Vercel/Netlify ready

## 📦 Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd My_Portfolio
```

2. Install dependencies:
```bash
npm install
```

3. Set up environment variables (optional):
Create a `.env` file in the root directory:
```env
VITE_EMAILJS_SERVICE_ID=your_service_id_here
VITE_EMAILJS_TEMPLATE_ID=your_template_id_here
VITE_EMAILJS_PUBLIC_KEY=your_public_key_here
```

4. Start the development server:
```bash
npm run dev
```

## 🚀 Deployment

The project is ready for deployment on platforms like Vercel, Netlify, or any other static hosting service.

```bash
npm run build
```

## 📧 Contact Form Setup

To enable the contact form functionality:

1. Sign up for EmailJS at [emailjs.com](https://www.emailjs.com/)
2. Create a service, template, and get your public key
3. Add the credentials to your environment variables or update the Contact.jsx component

## 🎨 Customization

- Update personal information in `src/pages/home.jsx`
- Modify project details in `src/component/Project.jsx`
- Customize colors and styling in Tailwind classes
- Add new sections by creating components in `src/component/`

## 📱 Responsive Design

The portfolio is fully responsive and optimized for:
- Mobile devices (320px+)
- Tablets (768px+)
- Desktop (1024px+)
- Large screens (1440px+)
